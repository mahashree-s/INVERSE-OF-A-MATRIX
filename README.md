# INVERSE-OF-A-MATRIX
## Aim:
To write a python program to find the inverse of a matrix
## Equipment’s required:
1. 	Hardware – PCs
2. 	Anaconda – Python 3.7 Installation / Moodle-Code Runner
## Algorithm:
### Step 1:

Import the `os` and `numpy` modules. Set `OPENBLAS_NUM_THREADS` to `1` for NumPy operations.

### Step 2:

Prepare the given matrix and assign it to a NumPy array using `np.array()`.

### Step 3:

Use `np.linalg.inv()` to calculate the inverse of the given matrix and store the result in `b`.

### Step 4:

Print the calculated inverse matrix and end the program.
